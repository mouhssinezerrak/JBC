Job Board Command

Privacy Policy

Effective October 31, 2026

Job Board Command is a Chrome extension that helps its users track remote job applications in a Google Sheet they own.

What it stores

Job listings, application status, notes, priorities and the job search profile entered in the sidebar: target titles, target role, resume text and filters. All of it is saved in the user's own Google Sheet, through a Google Apps Script the user controls. The extension keeps only basic settings in Chrome storage, such as the linked sheet and the selected job seeker.

What it sends

  • To find jobs, it requests public listings from job boards (Remotive, RemoteOK, Jobicy, We Work Remotely).
  • To score how well a job fits, it sends the job description, target titles and resume text to Google's Gemini API.

Nothing else is shared.

Gmail

When the user chooses a message template, the extension can place it into an open Gmail compose window. It does not read, store or send the content of the user's emails.

What it does not do

It does not sell data, show ads, or use analytics or tracking.

Google user data

Use of information received from Google APIs follows the Chrome Web Store User Data Policy, including the Limited Use requirements.

Your control

Delete any row in your sheet to remove that data, or uninstall the extension to stop all collection.
